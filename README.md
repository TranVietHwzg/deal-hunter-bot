# DEAL HUNTER PRO - BOT SĂN DEAL & VOUCHER CÁ NHÂN

Hệ thống săn deal Shopee cá nhân thông minh, tập trung vào các deal giảm từ **≥ 30%** và tự động gộp **Voucher Shop + Voucher Sàn + Freeship**.

## 1. Khởi chạy hệ thống
- Cách 1: Nhấp đúp chuột vào file `run.bat`
- Cách 2: Chạy lệnh bằng PowerShell:
  ```powershell
  & "C:\Users\ADMIN\AppData\Local\Python\bin\python.exe" main.py
  ```

## 2. Giao diện Web Dashboard
- Mở trình duyệt truy cập: `http://localhost:8000`
- Quản lý Watchlist, thêm món mới bằng link Shopee, xem độ giảm giá thực tế và kho voucher xịn.

## 3. Điều khiển qua Telegram (@San_deal_Huvg_bot)
- Gõ `/start` hoặc `/menu` để mở bàn phím nút bấm cảm ứng.
- Gõ `/add <link_shopee> 30%` để thêm món cần canh giảm từ 30% trở lên.
- Gõ `/list` để xem danh sách đang canh.
- Gõ `/check` để bắt bot quét ngay lập tức.
